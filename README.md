# Sushmita Nanda — Brand Storyteller

An editorial portfolio for Sushmita Nanda, built with Next.js, React,
TypeScript, Tailwind CSS and Framer Motion.

## Run locally

```bash
npm install
npm run dev:next
```

Open `http://localhost:3000`.

## Production builds

```bash
npm run build:next
```

The repository includes `vercel.json`, so it can be imported and deployed as a
Next.js project on Vercel. `npm run build` retains the compatible Sites build
used by the private hosted preview.

## Content

Project content lives in `data/projects.ts`. Portfolio imagery is organized in
`public/images/portfolio/`. Replace the canonical URL placeholder in the
metadata files when the final custom domain is connected, and add Sushmita's
LinkedIn profile URL in the contact section when it is available.
